# NovaCalc – Scientific Calculator

## Project Description
NovaCalc is a modern and user-friendly calculator developed using HTML, CSS, and JavaScript. It provides basic arithmetic operations, scientific calculations, GST and discount calculations, unit conversion, and calculation history.

## Features
- Basic Arithmetic Operations
- Scientific Calculator
- Multiple Color Themes
- Dark Mode
- Calculation History
- GST Calculator
- Discount Calculator
- Unit Converter
- Button Sound Effects
- Keyboard Support

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
